Modern altyapılarda aynı anda fiziksel sunucular, sanallaştırma platformları, network cihazları, firewall’lar, access point’ler ve bunların üzerinde çalışan onlarca farklı yazılım bulunur. Mail server’lar, dosya sunucuları, kamera sistemleri, web uygulamaları, sektöre özel iş yazılımları… Hepsi aynı anda ayakta durmak zorundadır.
